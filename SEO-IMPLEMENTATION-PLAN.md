# SEO implementation and launch checklist

- Each calculator, converter, simulation and guide has a stable semantic URL.
- Metadata is descriptive; title templates are centralized.
- WebSite JSON-LD is included; add page-level SoftwareApplication/Article schema only after the relevant content and claims have been verified.
- Sitemap is generated from the content registries only when `NEXT_PUBLIC_SITE_URL` is configured.
- robots.txt allows crawling and advertises sitemap when canonical URL is configured.
- No keyword volume, KD, CPC, SERP difficulty or ranking forecast is invented.
- Group variants by search intent; do not create duplicate pages for superficial wording changes.
- Manually validate the top 10 organic results and actual Semrush country database before indexing each calculator/guide cluster.
- Keep pages out of the sitemap if they have not passed scientific, UX and content review.
- Avoid thin AI-generated text: add original diagrams, transparent worked examples, source citations and clear differentiators before indexing.

## Important pre-launch gate
The 35 guide drafts and 150+ formula entries are initial educational content, not a substitute for subject-matter review. Check equations, symbol definitions, assumptions, source citations, worked examples and accessibility before public launch.
